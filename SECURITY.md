# Security

## Reporting

For now, report security issues privately to the repository owner instead of opening a public issue.

## Sensitive data rules

- Do not commit secrets, API keys, signing certificates, provisioning profiles, database dumps, or production credentials.
- Do not include exact private creation coordinates in public API responses, docs examples, screenshots, or test fixtures.
- Do not expose admin/moderator tooling publicly without explicit review and access controls.
- Do not add production deploy actions without a scoped issue and human approval.

## Current status

EchoTrails is pre-beta. The generated iOS prototype is reference-only and not production-ready.
