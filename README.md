# EchoTrails

Public place-stories for real-world locations.

Core promise: people leave short Echoes tied to real-world Places so others can discover the stories of those Places.

## Status

Early product/technical planning plus generated iOS prototype reference.

Current codebase:

- native SwiftUI iOS prototype generated by Rork
- Go API server primitive packages under `apps/api`
- product/technical planning docs
- Open Pilot-ready issue and PR templates

Planned beta:

- iOS TestFlight app
- custom Go REST API
- Postgres/PostGIS
- Redis jobs
- S3-compatible media storage/CDN
- React/Vite admin web
- minimal public preview web

## Quick start

```bash
make verify
```

Linux verification currently checks repo structure, docs, Open Pilot templates, committed secret filenames, and scaffold-aware Go, TypeScript, OpenAPI, and Swift gates. Missing implementation scaffolds are skipped with explicit messages; Swift/Xcode checks run only on macOS. With `apps/api` present, verification runs Go fmt/vet/tests for the API.

## API

The Go API lives under `apps/api` and currently exposes passwordless email auth and session endpoints:

- `POST /auth/email/start`
- `POST /auth/email/verify`
- `POST /sessions/refresh`
- `POST /sessions/logout`

Local development can run the API with `ECHOTRAILS_AUTH_EMAIL_DEV=1`; that opt-in dev adapter prints email codes for manual testing and must not be used in production.

## Open Pilot

This repository keeps the base Open Pilot issue template and PR template.

Agent-ready issues must include:

- `ready-for-agent`
- deterministic test command
- clear acceptance criteria
- explicit out-of-scope notes

Add `agent:queued` only after human review.
